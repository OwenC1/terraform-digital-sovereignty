# AI Assistance Disclosure

## AI Tool Used

**Tool:** ChatGPT (OpenAI)  
**Model:** GPT-6

ChatGPT was used as a learning and development assistant throughout this project. It helped explain Terraform and Sentinel concepts, provided implementation guidance, assisted with troubleshooting and supported the preparation of documentation.

## Examples of Prompts Used

The following are representative examples of the questions and requests made during development, rather than a complete transcript:

- Explain how Terraform differs from AWS CloudFormation.
- Explain the steps involved in creating a Terraform project.
- Explain how Terraform modules work and why they are useful.
- How can Sentinel enforce AWS infrastructure deployment only in Ireland?
- Help me create Sentinel policies for EC2 security and IaC supply-chain security.
- Explain how to test Sentinel policies using compliant and non-compliant mock data.
- Why is my Sentinel sovereignty policy failing in HCP Terraform?
- How can I check the actual AWS region used in a Terraform plan?

## Review and Verification

AI-generated suggestions were reviewed and tested during development. Terraform configurations were checked using Terraform commands, Sentinel policies were tested locally, and the sovereignty policy was evaluated in HCP Terraform.
